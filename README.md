Proyecto Aura - Universo Olfativo



Sitio web multipágina desarrollado como pre-entrega para el curso de Desarrollo Web de Coderhouse, enfocado en un catálogo digital de perfumería y asesoría olfativa.



Secciones del sitio:



Inicio: Presentación, carrusel de productos destacados y reseñas de usuarios.



Productos: Catálogo organizado por casas perfumistas.



Perfil olfativo: Test interactivo para la selección de fragancias.



Sobre nosotros: Propuesta de valor e información institucional.



Contacto: Canales de comunicación y formulario de atención.



Tecnologías utilizadas:



HTML5



CSS3 (Estilos propios y Media Queries para diseño responsive)



Bootstrap 5 (Grillas y barra de navegación)



Git y GitHub
